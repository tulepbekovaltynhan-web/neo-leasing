# Neo Leasing — демо-прототип

Кликабельный прототип мобильного приложения «маркетплейс автомобилей + лизинг»: подбор свайпами, умный подбор, калькулятор, сравнение, оформление с доставкой и личный кабинет.

**Все автомобили, цены и условия — демонстрационные и не являются офертой.**

## Как открыть
Откройте ссылку GitHub Pages на телефоне. Чтобы поставить как приложение:
- iPhone (Safari): «Поделиться» → «На экран „Домой“»;
- Android (Chrome): меню ⋮ → «Добавить на главный экран».

## Режим презентации
Кнопка ▶ в шапке открывает панель ведущего: переход к любому моменту сценария в один тап.

## Файлы
- `index.html` — всё приложение (один файл, без сборки);
- `manifest.webmanifest`, `sw.js`, `icons/` — установка на телефон и работа офлайн.
